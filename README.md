# Muyyi Srors — Portfolio

A personal developer portfolio built with HTML, CSS, and vanilla JavaScript.

## Structure
- `index.html` — Main page (single-page with anchor sections)
- `style.css` — Ethos light theme and responsive styles
- `script.js` — Scroll reveal, custom cursor, nav, contact form

## Sections
1. **Hero** — Name, tagline, CTA
2. **About** — Bio, facts card, experience timeline
3. **Projects** — 4 project cards with illustrated mockups
4. **Skills** — Grouped by category (languages, tools, soft skills, human languages)
5. **Contact** — Social links + message form

## To add a real photo
Replace the `.photo-placeholder` in `index.html` with:
```html
<img src="photo.jpg" alt="Muyyi Srors" style="width:100%; height:240px; object-fit:cover; object-position:top;">
```

## To deploy on GitHub Pages
Push all files to your `azureohizone.github.io` repository (or a `gh-pages` branch) and it will be live automatically.
